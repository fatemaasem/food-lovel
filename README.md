# Food Lover

A responsive single-page restaurant website built with HTML and CSS. The page presents a restaurant concept through a hero section, menu, offers, opening times, gallery, and contact area.

## Sections

- Responsive navigation and hero
- About section
- Promotional offers
- Two-column food menu
- Opening-time cards
- Image gallery
- Contact information and form
- Social media links

## Tech Stack

- HTML5
- CSS3
- Font Awesome

## Run Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/fatemaasem/food-lovel.git
cd food-lovel
```

No build step or backend is required.

## Project Structure

- `index.html` — page content and sections
- `style.css` — layout, responsive styling, and visual design
- `img/` — restaurant, menu, offer, and gallery assets
